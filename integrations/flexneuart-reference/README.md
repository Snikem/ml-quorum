# Историческая интеграция с FlexNeuART

Здесь сохранены исходные адаптер, его интеграционный тест, сравнение выдачи и
конфигурация. Файлы `.java.txt` — справочные снимки, они не компилируются.
Поиск теперь доступен через `monoforest.MonoforestSearch`, сравнение с BM25 —
через `monoforest.impl.testSearch`. Документ MONOMIAL_CANDIDATES.md описывает
прежнюю интеграцию и не является инструкцией запуска отдельного проекта.

Будущий адаптер должен жить на стороне FlexNeuART и зависеть от JAR Monoforest.
